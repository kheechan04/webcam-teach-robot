# M8 웹캠 시범 녹화 규칙 (2026-10-03 확정)

- 스크립트: `scripts/record_demos.py` → `measurements/demos_m8/`
- 조종 코드는 `src/webcam_teach_robot/teleop_rig.py` 하나를 자유 조종(`teleop.py`)과 녹화가 같이 쓴다. 조건 ②와 ③의 차이는 깊이 보정(`depth_correction.py`)을 켜느냐뿐이다. 옮기기 전과 같은 손 입력으로 목표 위치·집게가 프레임마다 똑같이 나오는 것을 확인했다.

## 규칙

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 개수 | 학습 배치 50개(`layouts_v1.json` train) × 조건 ②·③ = 100번 | 조건 ①과 같은 배치·같은 개수 |
| 순서 | 5개씩 10블록. 블록마다 같은 5개를 한 조건으로 다 하고 다른 조건으로 다시. 먼저 할 조건은 블록마다 ABBA 반복(A는 시드로 정함), 블록 안 배치 순서는 조건마다 섞음 | 연습 효과·피로가 한 조건에 쏠리지 않게 |
| 가리기 | 화면에 조건을 표시하지 않음(깊이 숫자도 숨김). 기록 JSON에만 남음 | 조작자가 조건을 알고 다르게 행동하는 것을 줄이려고 |
| 시간 제한 | 조종을 처음 건 때부터 90초 | 끝없이 붙잡고 있지 않게. 성공 기록 하나가 74초였음 |
| 다시 하기 | 같은 배치·조건 3번까지. 3번 다 실패하면 실패로 남기고 넘어감 | 실패도 결과(조종이 얼마나 어려웠나) |
| 포기 | `x` = 실패 1회로 셈 | 정직하게 세려고 |
| 중간에 끄기 | 끝나지 않은 시도는 "interrupted"로 남기고 횟수에 안 넣음. 다음 실행 때 그 배치부터 | 노트북이 꺼져도 잃는 것 없게 |
| 성공 판정 | `PlacementTracker`(다른 모든 곳과 같음). 성공 뒤 1.5초 더 기록하고 저장 | |
| 데이터셋 | 녹화 화면이 성공으로 끝낸 시도만, 그리고 `build_dataset.py`가 판정을 다시 계산해서 성공인 것만 | 두 번 확인 |
| 저장 | 시도마다 CSV(숫자만, 손 마디 원래 값 포함) + JSON(조건·배치·설정·보정 계수·git 커밋). 진행은 `progress.json` | 영상은 저장하지 않음 |

실패가 나오면 두 조건의 성공 시범 수가 달라질 수 있다. 학습할 때 맞출지(적은 쪽에 맞춰 뽑기)는 녹화가 끝난 뒤 정하고, 녹화 중 성공률 자체도 결과로 쓴다.

## 하는 법

1. (처음에만) 몸풀기: `uv run python scripts/teleop.py`로 5분쯤 자유롭게. 기록하지 않는다.
2. `uv run python scripts/record_demos.py`
3. 웹캠 창을 클릭하고 `스페이스`로 조종 시작. 큐브를 집어 초록 사각형에 놓고 손가락을 벌리면 성공.
4. 끝나면 화면 안내대로 `n`. 블록(10번)이 끝나면 쉬라고 나온다. 그만하려면 `q`. 다음에 같은 명령으로 이어서.
5. 진행만 보려면 `uv run python scripts/record_demos.py --status`

녹화가 끝날 때마다 Claude가 기록을 확인하고 커밋한다.
