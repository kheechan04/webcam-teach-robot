# 피드백 기록

개인 프로젝트의 한계를 보완하려고 진행 과정을 비공개 SNS 계정에 올리고, 도움이 될 것 같은 동기·친구들에게만 공유해 피드백을 받는다. 받은 질문·제안과 그 결과를 남긴다.

- 사람은 이름 대신 역할로 적는다(예: 같은 학과 동기, 친구). 이름을 쓰려면 본인 허락을 받는다.
- "같이 연구했다"가 아니라 "피드백을 받았다"로 적는다.

### 후속 확인 (2026-10-03, M5 정식 측정)

두 질문에서 나온 보정 후보 1(화면과 나란한 성분)·2(손목–새끼 뿌리)를 정식 측정으로 다시 비교했다. 조종이 이미 쓰는 "길이·너비 중 작은 값"보다 뚜렷이 낫지 않았다(평균 절대 오차 5.8 vs 6.3·7.8 cm). 질문 덕분에 오차 구조를 더 정확히 알게 됐고(남는 건 자세별 일정한 치우침), 보정 방향을 바꿨다 (`docs/06-depth-formal.md`).
