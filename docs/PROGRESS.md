4. 역기구학: `src/webcam_teach_robot/ik.py` 완성. 우선순위 IK(1순위 위치, 2순위 집게 아래 방향, 영공간 사용, 관절 한계 처리). 격자 48점 테스트: 도달 가능한 92% 전부 위치 오차 <2 mm(중앙값 0.14 mm), 높이 3 cm에서 방향 오차 ≤2.6°, 풀이 약 6.6 ms
